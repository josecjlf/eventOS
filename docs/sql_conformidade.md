# Conformidade SQL

Os scripts do pacote usam SQL padronizado conforme as restrições de recursos fornecidas para o trabalho. A reprodução utiliza PostgreSQL e pgAdmin, conforme o [README](../README.md).

O DDL atual tem cinco tabelas, 28 colunas, cinco identidades, cinco PK, três UNIQUE, quatro FK simples, 21 CHECK nomeados, 23 colunas obrigatórias e cinco opcionais. Categoria é global; Inscrição referencia Categoria e Edição separadamente. Não há FK composta no esquema atual. Oito estruturas únicas previstas, sem CREATE INDEX adicional.

| Categoria de recurso restrito | Resultado atual |
| --- | --- |
| SERIAL/BIGSERIAL e aliases | Não utilizados; BIGINT GENERATED BY DEFAULT AS IDENTITY |
| TEXT/MONEY/BYTEA/UUID | Não utilizados; VARCHAR(n) e DECIMAL(12,2) |
| JSON/JSONB/JSONPATH/ENUM/ranges/rede/geométricos/internos | Não utilizados |
| Catálogos específicos e funções pg_* | Não utilizados; somente INFORMATION_SCHEMA |
| COPY/ON CONFLICT/RETURNING/UPDATE FROM/DELETE USING | Não utilizados |
| SELECT sem FROM/IF EXISTS/IF NOT EXISTS | Não utilizados |
| Funções de sequência/generate_series/random/:: | Não utilizados; reinício padronizado por ALTER TABLE |
| Extensões/rotinas/triggers/rules/policies/full-text | Não utilizados |
| CTE com DML/opções de materialização | Não utilizadas; CTE pertence ao SELECT fonte de INSERT |
| CREATE ROLE/privilégios específicos de database/schema | Fora do SQL; preparação administrativa pelo pgAdmin |
| GRANT/REVOKE com vários objetos | Não utilizados; concessões individuais, REVOKE RESTRICT |
| Índices adicionais/benchmark | Não utilizados; apenas PK/UNIQUE |

CHECK tem somente predicados de linha, sem leitura de outras tabelas. SERIALIZABLE e operação controlada continuam procedimentos que podem exigir repetição integral; diagnóstico detecta, não previne. Os metadados incluem onze consultas M00–M10 somente em INFORMATION_SCHEMA. Recursos representados pelo servidor em CSVs/logs não são comandos usados pelos scripts.

M00–M09 foram [conferidos contra o DDL](../evidencias/metadados/resultados.md), sem divergências. Casts `::`, referências a `text`, arrays e funções na representação de DEFAULT/CHECK exportada pelo servidor são conteúdo das capturas; esses recursos não foram introduzidos nos scripts executáveis.
